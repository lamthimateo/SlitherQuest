
# Snake Game

A simple Snake game built with Java and Swing. Control the snake, eat apples, grow longer, and avoid collisions. The game speeds up as you level up, with a goal to reach level 10.

## Features
- **Smooth Gameplay**: Snake grows and speeds up with each level.
- **Levels**: 10 levels with increasing difficulty.
- **Pause/Resume**: Pause the game with the `P` key.

## Installation
1. Ensure JDK is installed.
2. Clone the repo:
   ```bash
   git clone https://github.com/lamthimateo/SlitherQuest
   ```
3. Open the project in an IDE and run `Snake.java`.

## Controls
- **Arrow Keys**: Move the snake.
- **P**: Pause/Resume the game.
